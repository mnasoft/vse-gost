
* Введение
Проект [[Проект *vse-gost*][*vse-gost*]] *vse-gost* предназначен для разбора информации о
ГОСТ, размещенной на сайте [[http://vsegost.com]].

Проект [[Проект *vse-gost/web*][*vse-gost/web*]] предназначен для создания web-сервера,
предоставляющего содержимое ГОСТ (отзеркалированных с сайта
[[http://vsegost.com]]).

* Проект *vse-gost*
Здесь приведена [[./org/catalog.org][структура каталогов]] сайта vsegost.com.

Проект содержит инструкции по:
1. [[./org/instruction-mirroring.org][Зеркалированию сайта vse-gost.com]]
2. [[./org/instruction-import-file.org][Генерированию файла импорта для ДБ PostgreSQL]]
3. [[./org/instruction-postgesql.org][Установке и настройке PostgreSQL]]
4. [[./org/instruction-gost.org][Созданию базы данных gost]]

* Проект *vse-gost/web*
Предназначен для создания web-сервера, предоставляющего содержимое
ГОСТ (отзеркалированные с сайта  [[http://vsegost.com]]).

Проект содержит инструкции по:
1. Установке и запуску web-приложения под Linux
   - [[./org/instruction-build-web-app.org][Установка *vse-gost/web*]]
   - [[file:org/instruction-start-web-app.org][Запуску веб приложения]]
2. Установке и запуску web-приложения под Windows
   - см. [[file:org/n133906.org]]
