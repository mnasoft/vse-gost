
* Сборка выполняемого файла, запускающего веб-сервер
#+begin_src lisp
  (asdf:load-system "vsegost/web")

  (sb-ext:save-lisp-and-die "vsegost-web.exe"
                            :executable t
                            :compression t)
#+end_src

#+begin_src sh
  vsegost-web.exe --eval "(vse-gost/web:start-gosts)"
#+end_src

** Запуск standalone
Обычный запуск:
#+begin_src shell
  vsegost-web.sh
#+end_src

Прямой запуск бинарника:
#+begin_src shell
  vsegost-web.exe --eval "(vse-gost/web:start-gosts)"
#+end_src

Запуск в tmux:
#+begin_src shell
  vsegost-web-tmux.sh
#+end_src

Опционально можно задать имя tmux-сессии:
#+begin_src shell
  SESSION_NAME=vsegost-web vsegost-web-tmux.sh
#+end_src

* Standalone сборка/установка (Linux)
Для standalone используется SBCL-образ без параметра =:toplevel=.
Запуск выполняется командой:
#+begin_src shell
  vsegost-web.exe --eval "(vse-gost/web:start-gosts)"
#+end_src

* Сборка выполняемого файла, запускающего веб-сервер
1. Запустите sbcl в консоли
2. Выполните код в SBCL
   #+begin_src sh :results none
     mkdir -p ../src/web/build 
     cd ../src/web/build 
     sh ../sh/build.sh
   #+end_src

* Запуск сервера
В отдельной консоли необходимо выполнить
#+begin_src shell
  vsegost-web-tmux.sh
#+end_src
