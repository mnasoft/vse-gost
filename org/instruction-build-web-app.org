* Установка *vse-gost/web* под Linux
Сборка, установка и создание севиса осуществляется при помощи скрипта
[[file:~/quicklisp/local-projects/clisp/vse-gost/INSTALL.sh][=INSTALL.sh=]].

Скрипт [[file:~/quicklisp/local-projects/clisp/vse-gost/INSTALL.sh][=INSTALL.sh=]] необходимо запускать из консоли из каталога, в
котором раслолагается шрифт.

Рекомендуемый метод сборки и установки приведен в следующем [[Рекомендуемый метод сборки и установки][разделе]].

** Рекомендуемый метод сборки и установки
#+caption: Сборка, установка и создание systemd-сервиса
#+begin_src shell
  ./INSTALL.sh build
  ./INSTALL.sh install
  ./INSTALL.sh service-install  
#+end_src
